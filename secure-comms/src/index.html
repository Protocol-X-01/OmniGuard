About this local release and mobile access

This exercise runs only on this computer. Room membership, timing and device identifiers are visible to the server. Encryption does not protect a compromised device.

Keys and sign-in tokens stay in memory for this session. End the session before closing the tab. There is no recovery or durable history in this release; a refresh creates a new device that must be verified again.

Android and iOS access will use a reachable HTTPS Matrix server and verified mobile clients. This local loopback server cannot be reached from a phone, and physical mobile acceptance is still pending.
