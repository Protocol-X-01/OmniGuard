# Guard-anchor regression — engine 0.1.3

An independent adversarial review found that the 0.1.2 authorization heuristic accepted an owner equality after that same function had assigned the owner from its caller. Both source and compiler modes returned a complete, finding-free report for this isolated pattern:

```solidity
owner = msg.sender;
require(msg.sender == owner);
(bool ok,) = target.delegatecall(data);
require(ok);
```

The equality restricts nobody in this invocation. Version 0.1.3 rejects that suppression when an earlier direct write may have changed the exact storage binding used by the caller comparison. It inspects assignments, tuple assignments, augmented assignments, updates and deletion. Binding resolution distinguishes shadowed locals and unrelated state writes. Branch writes are treated conservatively.

The same predicate also supports other local-caller restrictions, including the selfdestruct indicator. This change does not establish that an unchanged address variable is globally trustworthy.

## Reproduce

```sh
cargo test --workspace
OMNIGUARD_TEST_SOLC=/path/to/native/solc cargo test --workspace -- --ignored
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release --workspace
```

`crates/omniguard-core/tests/guard_anchor.rs` independently authors fifteen cases in each source/compiler mode. They include caller/parameter/tuple/branch/delete writes, conditional/denial checks, poisoned and stable modifiers, unchanged and immutable anchors, unrelated writes, local shadows, an authorized owner rotation and an unguarded control. Delegatecall results are checked so the tests isolate authority reasoning. Native tests used Solidity 0.8.26; all thirty scans had complete coverage, expected OG-SOL-005 presence/absence and validated evidence.

The patch also fixes a measured input-coverage inconsistency: canonicalization previously hid an explicitly selected symbolic link. File, directory and dangling-link inputs now produce incomplete coverage with a `symlink-skipped` diagnostic in both analysis modes. This is a selected-entry check, not a host filesystem confinement policy for every ancestor or a defense against concurrent filesystem replacement.

## Remaining analysis gaps

This is bounded local guard invalidation. Public setters in another transaction, helper-mediated or assembly writes, imported/inherited modifier semantics, interactions between modifiers, storage-reference aliases, reassigned value propagation and interprocedural effects need stronger modeling. A branch that cannot execute can conservatively retain a finding. The regression cases are development tests, not independent production precision/recall measurements. No new EVM exploit or live-target execution was performed for this patch.
